# Project skills

The `roblox-*` skills in this folder come from
[TabooHarmony/roblox-brain](https://github.com/TabooHarmony/roblox-brain)
(MIT license, see `ROBLOX-BRAIN-LICENSE`), copied at commit `38826be57ee37bcf023e9c2b85681bea3909281c`.

Claude Code loads them automatically for this project. `CLAUDE.md` (the
Loot Lighthouse brief) wins whenever a skill's advice conflicts with it.

To update: re-copy each `skills/<library>/<skill>/` folder from upstream.

The other skills (`roblox-game-ideas`, `roblox-to-prd`, `handoff`, `zoom-out`,
`setup-roblox-skills`, ...) come from
[AshExplained/roblox-skills](https://github.com/AshExplained/roblox-skills)
(MIT license, see `ASHEXPLAINED-LICENSE`), copied at commit `a3a7b940f0899d4a69c1a7df625996bdfc917388`.

Note: that pack assumes game code lives only in Studio and is never committed
to Git. This project uses Rojo with code in `src/` (see `CLAUDE.md`), so
`CLAUDE.md` wins on that point.
