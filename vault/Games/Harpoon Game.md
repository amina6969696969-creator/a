# Harpoon Game

- Kern: harpoen schieten, schatten binnenhalen met een reel-minigame.
- WANTED-bord: 3 schatten per dag ×3, nieuwe lijst om 02:00 (NL).
- Seizoen 1 "Sunken Kingdom": 30 niveaus, Coral Harpoon op niveau 30.
- Vriendenbonus: +10% goud per vriend, max +30%.
- Wensen: hotbar 1-0, Fisch-achtige rugzak, gewicht + grootte per schat, betere modellen, betere geluiden, vlekkeloze harpoen.
- Bestanden: harpoon-game/ in deze repo (MerchantStand.rbxmx, BuildMerchantStand.lua).
